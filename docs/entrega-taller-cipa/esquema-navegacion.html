Esquema de navegación HTML

Mapa de pantallas del software odontológico. La navegación cambia según el rol: visitante, paciente, profesional u administrador. Cada bloque enlaza a una página HTML de demostración.

Menú rápido (anclas internas)

Público Paciente Profesional Administrador Flujo de una cita Tabla de rutas

Estas anclas simulan el menú interno de una página larga, como en el taller de HTML.

1. Zona pública (sin iniciar sesión)

Visitante

Pantallas

  • Inicio / landing — presentación del servicio
  • Buscar especialistas
  • Ficha pública del profesional
  • Ingresar · Crear cuenta (paciente) · Soy especialista · Registrar centro

Ver demo de navegación pública

2. Navegación del paciente

Rol: Paciente

Menú lateral / portal

  • Mi perfil
  • Agendar cita (acción principal)
  • Mis citas (pendientes, confirmadas, canceladas)
  • Mi historia clínica (lectura)
  • Facturas y notificaciones
  • Editar perfil · Salir

Ver demo paciente

3. Navegación del profesional

Rol: Profesional

Menú del consultorio

  • Panel profesional
  • Agenda (día / semana)
  • Mis pacientes · Ficha clínica
  • Disponibilidad / horarios y sedes
  • Editar perfil · Notificaciones · Salir

El paciente no ve Agenda; el profesional no ve Mis citas. Cada rol solo navega lo suyo.

Ver demo profesional

4. Navegación del administrador

Rol: Administrador
  • Panel de administración
  • Gestionar profesionales (verificar / desverificar)
  • Gestionar pacientes · Nuevo paciente
  • Auditoría de acciones sensibles

Ver demo administrador

5. Flujo de navegación: agendar una cita

Inicio
→
Buscar especialista
→
Ficha pública
→
Agendar cita
→
Mis citas

Tras un POST exitoso el sistema muestra un mensaje de éxito y redirige a la lista del rol (Mis citas o Agenda), sin dejar el formulario vacío.
